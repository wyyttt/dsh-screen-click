# dsh-screen-click（第五人格准备）

一个 [DeepSeek Harness](https://github.com/deepseek-ai) 桌面版插件：在左侧栏加入「第五人格准备」入口，监测 `dwrg.exe` 游戏窗口里的「准备案件还原」按钮，按钮出现时自动连续点击，按钮消失后自动停止监测。

## 功能

- 左侧栏入口，点击图标即可开始监测（面板打开时也会自动开始）；
- 只监测 `dwrg.exe` 的主窗口：窗口在前台时用屏幕截图，在后台时用 `PrintWindow` 抓取窗口画面；
- 命中「准备案件还原」按钮后，如果游戏不在前台，会先自动把窗口切到前台，再移动真实鼠标点击按钮中心；
- 按钮连续 3 次检测不到（约 1～2 秒）后自动停止，并保持停止状态，等待你重新开始；
- 面板实时显示状态、点击次数、匹配分和最近事件日志，便于排查问题。

## 环境要求

- Windows 10/11；
- DeepSeek Harness 桌面版（插件使用 DSH 运行时自带的 Python 与 Pillow/numpy，无需单独安装 Python）；
- 参考分辨率为 1920×1080（窗口不是该分辨率时会按比例换算检测区域和点击点）。

## 安装

在 DSH 的插件管理器中安装本仓库（git 地址），或者把仓库目录作为本地插件包安装：

```text
插件管理 → 安装 → 填入仓库地址或本地目录路径
```

插件以 `@local/dsh-screen-click` 作为包名，row id 为 `screen-click`。

## 使用

1. 启动游戏（进程名 `dwrg.exe`）；
2. 点击左侧栏的「第五人格准备」图标（或打开该面板，它会自动开始监测）；
3. 确认面板显示「监控中 / 等待目标画面出现」，然后切回游戏或做别的事；
4. 出现「推演成功」界面的「准备案件还原」按钮时，插件会自动切前台并连续点击，直到按钮消失；
5. 按钮消失后监测自动停止；需要再次使用就重新点侧栏图标或面板里的「重新开始监测」。

不用时请在面板里点「停止监测」，避免监测进程一直挂着等待目标。

## 工作方式

1. `helper.py` 找到 `dwrg.exe` 的可见主窗口，前台时截取屏幕对应区域，后台时用 `PrintWindow` 抓取窗口；
2. 把按钮区域缩放到 40×12 灰度签名，与 `signature.json` 中的目标签名比较，平均绝对差 ≤ 45 视为命中；
3. 命中后若游戏不在前台，先 `SetForegroundWindow` + `AttachThreadInput` 切换前台，再用 `SetCursorPos` + `mouse_event` 真实点击；
4. 目标消失（连续 3 次未命中）后退出监测进程。

`signature.json` 包含参考分辨率、检测区域、签名、阈值和点击坐标。如果你更换了分辨率、UI 缩放或目标按钮外观，需要重新生成签名。

## 文件结构

```

├── cordis.patch.yml    # Loader 插件行

├── client.js           # Client 半：侧边栏入口 + 状态面板

├── icon.svg            # 插件图标
└── locale/             # 插件显示名称与描述（中/英）
```

## 已知限制

- 点击必须落在最上层窗口，因此命中时游戏会被切到前台（会抢焦点）；
- 个别独占全屏或 GPU 渲染方式下 `PrintWindow` 可能返回黑屏，此时需要让游戏窗口保持可见；
- 游戏窗口最小化时可能无法截图；
- 监测在等待目标期间会一直运行，一个 Python 进程约每秒做 2～3 次截图比对。
